## 2026-11-03 - Accessible Custom Upload Zones with Hidden File Inputs
**Learning:** When using a custom drop zone wrapping a hidden file input (`<input type="file" hidden>`), keyboard users and screen readers are completely locked out of the upload action unless the drop zone container is explicitly given `role="button"`, `tabindex="0"`, an `aria-label`, and `keydown` handler for `Enter`/`Space`. Additionally, child buttons inside the clickable drop zone should be given `tabindex="-1"` to prevent nested duplicate tab stops.
**Action:** When creating or refining styled file drop zones, always give the drop zone container keyboard focusability (`tabindex="0"`), clear role and aria-label, handle `keydown` (Space/Enter), and ensure child decorative buttons have `tabindex="-1"`.
